# Release Verification & Provenance

This document describes how to independently verify the cryptographic provenance and integrity of Warm-AntiCheat releases and contest packages.

---

## 1. Verifying Official Binary Checksums

Every release published to GitHub Releases includes a `SHA256SUMS.txt` checksum manifest.

To verify on Windows (PowerShell):
```powershell
Get-FileHash -Algorithm SHA256 ./Warm-AntiCheat-Participant.exe
```

To verify on Linux / macOS:
```bash
sha256sum -c SHA256SUMS.txt
```

---

## 2. Verifying Ed25519 Manifest Signatures

Official contest packages generated by the Contest Builder include a signed manifest:
- `contest_manifest.json`: The canonical JSON manifest.
- `contest_manifest.json.sig`: Hex-encoded 64-byte Ed25519 signature.

You can verify the signature using the built-in verifier command or via `warm_crypto`:
```bash
cargo run -p warm_judge_app -- verify-manifest \
  --manifest ./dist/GOCUP-1/manifests/contest_manifest.json \
  --signature ./dist/GOCUP-1/manifests/contest_manifest.json.sig \
  --public-key ./dist/GOCUP-1/configuration/manifest_signing_key.pub
```

Output:
```text
[OK] Signature verified successfully.
[OK] Manifest matches Contest UUID: 4f447f5e-149b-43d9-95cb-6be7a01c8091
[OK] Organizer: ICPC Regional Committee
```

## 3. Authenticode Digital Signature Verification (Windows)

Production Windows executables and MSI installers are signed with an Authenticode certificate. To verify the signature and timestamp:

```powershell
Get-AuthenticodeSignature .\warm_participant_app.exe | Format-List
```

Expected Output:
```text
SignerCertificate : [Subject: CN=Kasra Borjloo, ...]
Status            : Valid
StatusMessage     : Signature verified.
TimeStamper       : [RFC 3161 Timestamp Authority]
```

---

## 4. Antivirus & False-Positive Verification

Official release artifacts are screened against major antivirus engines before release.
- If an antivirus scanner flags an artifact (e.g., Bkav Pro `W32.Malware.9E43BB5C` or generic heuristic):
  1. Confirm the binary SHA-256 matches `SHA256SUMS.txt`.
  2. Inspect the reproducible build provenance from the GitHub Actions run.
  3. Consult [ANTIVIRUS_COMPATIBILITY.md](ANTIVIRUS_COMPATIBILITY.md) for vendor false-positive submission procedures.

---

## 5. Software Bill of Materials (SBOM) Verification

Every release includes an SPDX/CycloneDX SBOM (`sbom.spdx.json` / `sbom.cyclonedx.json`).
Verify dependency integrity:
```bash
cargo audit
```
