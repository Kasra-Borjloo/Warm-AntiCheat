# Example Contest: GOCUP 1

This directory showcases the official offline distribution bundle generated by the **Contest Builder** for a competition named **GOCUP 1** (`gocup-1`).

---

## Directory Layout

```text
examples/gocup-1/
├── client/
│   ├── windows/          # Participant Client package for Windows (.exe / .msi)
│   ├── linux/            # Participant Client package for Linux (.AppImage / .deb)
│   └── macos/            # Participant Client package for macOS (.dmg)
├── configuration/
│   ├── contest_config.json          # Public contest specification
│   ├── policies.json               # Prohibited apps & restricted domains
│   ├── judge_evidence_key.pub       # Public asymmetric encryption key (X25519)
│   └── manifest_signing_key.pub     # Public manifest signing key (Ed25519)
├── manifests/
│   ├── contest_manifest.json        # Canonical signed contest manifest
│   └── contest_manifest.json.sig    # Ed25519 digital signature (64-byte hex)
├── checksums/
│   └── SHA256SUMS.txt               # SHA-256 integrity checksums
└── VERIFICATION_INSTRUCTIONS.md     # Offline verification commands for judges
```

---

## Verification Quick-Start

To verify the Ed25519 digital signature of the manifest:

```bash
cargo run -p warm_judge_app -- verify-manifest \
  ./examples/gocup-1/manifests/contest_manifest.json \
  ./examples/gocup-1/manifests/contest_manifest.json.sig \
  ./examples/gocup-1/configuration/manifest_signing_key.pub
```
